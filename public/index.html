How to get credentials

Sleeper

Just your Sleeper username. No login needed.

ESPN

Log in to fantasy.espn.com in your browser, open DevTools → Application → Cookies → https://fantasy.espn.com, and copy the values of espn_s2 and SWID. Leagues are discovered automatically; if that fails, paste league IDs (from the league URL) separated by commas.

Yahoo

Create an app at developer.yahoo.com/apps (Installed Application, API permission "Fantasy Sports – Read"). Paste the Client ID and Client Secret, save, then click Connect Yahoo, approve, and paste the code Yahoo shows you.

CBS

CBS uses a per-league access token, so add one CBS entry per league. Log in at cbssports.com and open your league's home page (yourleague.football.cbssports.com). Then either:

  • View the page source (Ctrl+U) and search for token. Copy the long value from var token = "…"; or
  • Open DevTools → Network, filter for api.cbssports.com, click any request, and copy the access_token value from its URL.

Enter the league subdomain (the yourleague part) and the token.
